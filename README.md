# My_house

## Présentation

**My_house** est un projet de développement web ayant pour objectif de concevoir un site web accessible et intuitif.

Ce projet met en pratique les compétences acquises en développement web, notamment la structuration des pages, la mise en forme et l'intégration de fonctionnalités interactives.

## Technologies utilisées

- **HTML5** – Structure des pages web.
- **CSS3** – Mise en forme et design.
- **JavaScript** – Interactivité et dynamisme.

## Installation et utilisation

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/FADHEL028/My_house.git
   ```

2. Accéder au dossier :
   ```bash
   cd My_house
   ```

3. Ouvrir le fichier `index.html` dans un navigateur.

## Déploiement

Le site peut être hébergé gratuitement avec **GitHub Pages**.
